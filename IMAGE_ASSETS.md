# Images Needed for Learning Games 🎮

This app already works today using emoji everywhere. Every image below is **optional** —
the app automatically falls back to an emoji if an image is missing, so you can generate
as many or as few of these as you like, and drop them in whenever ready.

## How it works
1. Generate an image for a row below.
2. Save it as a **PNG** using the **exact filename** shown (case-sensitive).
3. Put it in: `riya-tech-games/public/images/<filename>`
4. Refresh the app in your browser — the image appears automatically. No code changes needed.

## Recommended style (use this in every prompt for a consistent look)
> "Flat vector illustration, cute and playful, bright bold colors on a transparent or white
> background, thick clean outlines, simple shapes, friendly rounded style suitable for a
> kids' learning app, no text or letters in the image, centered composition,
> square 1:1 aspect ratio."

Recommended size: **512×512px**, PNG, transparent background if possible.

### Notes
- All filenames are lowercase with hyphens, matching exactly what's in the code.
- PNG format only (the app looks for `.png`).
- If you skip any image, that game/card simply keeps showing its emoji — nothing breaks.
- Once you've generated a batch, just drop them all into `public/images/` at once.
